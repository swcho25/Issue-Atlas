## 컨셉

지도를 펼치듯 근거를 열어 보는 서비스. 지도 두 장을 접어 세운 첫 아이디어에서 출발해 **구상 → 면 → 아틀라스 → 펼침** 순서로 다듬었다.

- 두 면: 펼친 지도책. 왼쪽 면과, 뒤로 한 번 접혀 넘어간 오른쪽 면
- 사이의 빈 공간: 지역의 사람. 지구를 떠받치는 아틀라스 석상의 옆얼굴(곱슬머리)
- 펼침: 마우스를 올리면 오른쪽 면 윗날개가 휘며 안쪽 금색 면이 드러난다. 「원문을 펼쳐 근거를 본다」는 동작

## 구성

566 × 530 격자. 아래 값은 모두 격자 단위다.

| 항목 | 값 |
| --- | --- |

| 왼쪽 면 폭 | 202 |
| 옆얼굴 폭 | 95 — 왼쪽 면 오른쪽 변에서 코끝까지. 여백 단위 x |
| 기울기 | 뒤 접힘 윗변 16° · 오른쪽 면 윗변 13° · 왼쪽 면 아랫변 19° · 오른쪽 면 아랫변 17° |
| 바깥 모서리 R 40 (4곳) | 왼쪽 면 왼쪽 아래 · 왼쪽 면 오른쪽 위 · 오른쪽 면 오른쪽 위 · 오른쪽 면 오른쪽 아래 |
| 안쪽 모서리 r 20 (2곳) | 왼쪽 면 오른쪽 아래 · 뒤 접힘 오른쪽 위 |

| 반지름이 없는 곡선 | 왼쪽 위 말림 두 곳과 얼굴 윤곽. 원이 아니라 자유 곡선 |

곡선 규칙(코드 `contour.ts` 와 Figma `Logo/Symbol` 이 같은 계산)

- 28 보다 긴 변은 직선으로 둔다
- 모서리 호 · 얼굴처럼 짧은 점들은 점을 지나는 매끈한 3차 베지어로 잇는다
- 1.25 rad 보다 크게 꺾이는 곳(코끝 · 입술 · 틈 끝)은 뾰족하게 남긴다

## 만든 과정 (다시 만들 때)

1. 시안 09 그림을 비트맵으로 추적해 꼭짓점을 얻었다. 꼭짓점은 `frontend/src/shared/ui/logo/geometry.ts`
2. 모서리를 두 단계로 정리했다. 그림을 따라 그린 탓에 반지름이 19~47 로 제각각이었다. 각 모서리를 양쪽 직선 변에 접하는 정확한 원호(R 40 · r 20)로 바꿨다
3. 얼굴만 atlas-21 의 석상 옆얼굴로 바꿨다. 같은 폭(488)에 맞춰 옮긴 뒤 정수리(241, 169)와 목(247, 397) 사이에 끼우고, 양 끝 어긋남은 길이를 따라 고르게 나눴다
4. 추적 다각형(직선 + 아주 작은 둥글림)은 꺾인 직선처럼 보여서, 위 「곡선 규칙」의 매끈한 곡선으로 바꿨다
