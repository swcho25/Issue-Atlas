# 랜딩 스크롤 시제품 — 지구 → 구름 → 서울 지도

히어로의 아틀라스 지구에서 스크롤하면 지구가 서울 쪽으로 돌며 다가오고, 구름을 지나 지도로 바뀐 뒤 서울 구 단위까지 비스듬히 돌아 내려가 근거 점이 놓인다(`?at=gwangju` 면 광주).
도착 지역은 예시일 뿐이라, 화면 문구는 어느 지역에나 맞게 쓴다(나중에 전 세계로 넓힌다).
실제 랜딩(`frontend/src/pages/landing`)에 옮기기 전에 움직임 · 로딩을 맞춰 보는 시제품이다. 2026-11-02 에 고쳤고, 요청마다 커밋이 있다.

## 열기

```bash
node docs/design/landing-scroll/serve.js docs/design/landing-scroll 5199
```

http://localhost:5199/ — 오른쪽 아래에 진행률(p) · fps · 받은 지구 조각 · 지도 사진 수가 보인다.

| 주소 끝 | 하는 일 |
| --- | --- |
| `?p=0.5` | 그 지점으로 바로 간다 |
| `?at=gwangju` | 서울 대신 광주로 도착한다(지역마다 중심 · 구운 지도 · 도착 카메라 · 점 · 지명은 `index.html` 의 `SITES`) |
| `?map=bright` · `?map=blue` | 다른 지도 테마(먼저 `bake.html?style=bright` 처럼 구워야 한다. 저장소엔 liberty 만 있다) |
| `?bakestatue` | 석상을 실제로 계산해 그린다(미리 구운 `baked/statue-*.webp` 를 다시 만들 때) |
| `?capture` | Figma 로 옮길 그림을 뽑을 때. 캔버스를 읽을 수 있게 하고 히어로 지구를 처음 자세(오스트레일리아 정면)에 멈춘다 |
| `?timer` | 점검용. 창이 숨어 화면 갱신(requestAnimationFrame)이 멈출 때 타이머로 돈다 |

느린 인터넷 흉내: `node docs/design/landing-scroll/serve.js docs/design/landing-scroll 5201 400` — 모든 응답이 합쳐서 초당 400KB.

## 파일

| 파일 | 하는 일 |
| --- | --- |
| `index.html` | 시제품 |
| `bake.html` | 지도 장면 굽기. 도착 지역 한가운데를 중심으로 확대만 다른 2048px 정사각 사진을 `baked/<테마>-<지역>-<확대>.webp` 로 저장(`?at=seoul` · 없으면 광주로, 파일 이름에 지역 없음. `?style=liberty\|bright\|blue`, `?z=11.5,12.5` 몇 장만) |
| `shrink.html` | 지구 사진 나누기. 8K 원본 → 7KB 전체 사진 · 경도 45° 조각 8장 · 동아시아 8K 조각 · 구름 2K |
| `serve.js` | 정적 서버. `POST /save/<이름>` 으로 굽기 결과를 `baked/` 에 저장, 세 번째 인자로 속도 제한 |
| `baked/` | 구운 사진(서울 · 광주 liberty 지도 8단계씩, 지구 조각, 석상) |
| `earth_8192.webp` 외 | 굽기 원본. `frontend/public/landing` 과 같은 파일 |

## 장면(스크롤 진행률 p)

| p | 장면 |
| --- | --- |
| 0 ~ 0.03 | 히어로. 지구본을 끌어서 돌릴 수 있다 |
| 0.04 ~ 0.26 | 끌어 둔 자세에서 가장 짧은 방향으로 도착 지역을 향해 돈다. 히어로 글자는 사라지고, 석상은 지구를 받친 채 지구와 함께 올라가고 커지다 화면 아래로 빠진다 |
| 0.12 ~ 0.84 | 지구 카메라 높이 ↔ 지도 확대를 한 곡선으로 내려간다(확대 0.6 → 서울 10.65 · 광주 11.45). 0.5 ~ 0.84 에 42° 기울고 20° 돈다 |
| 지구가 화면을 다 덮은 뒤 확대 1.8 구간 | 지구 캔버스 투명도만 내려 같은 축척의 지도와 겹쳐 바꾼다(시작점은 화면 비율로 셈: 16:9 는 약 4.4, 4:3 은 약 3.3) |
| 0.27 ~ 0.58 | 반투명 구름이 스친다 |
| 0.72 ~ | 측정소(서울 10곳 · 광주 13곳) · 보도자료 3곳 점이 하나씩 놓인다(예시 위치. 서울 말풍선엔 값을 넣지 않았다) |
| 0.88 ~ 0.95 | 캡션 · 제목(「어느 지역이든, 근거는 지도 위에 쌓여요」 한 줄만. 위에 붙는 작은 설명 줄은 두지 않는다) |
| 지도 다음(스크롤 구간 밖) | 설명 섹션 셋(「판단보다, 근거부터 먼저」 화면 목업 셋 · 「말할 수 있는 만큼만, 분명하게」 판단 · 말하지 않는 것 · 「원문까지 두 번, 각주는 그대로」 네 단계) → 「어느 지역부터 볼까요?」 + OPEN THE ATLAS + 지역 줄(열린 곳 광주 · 여수만 테두리 + 앰버 점, 좌우로 천천히 흐름) → 푸터 |
