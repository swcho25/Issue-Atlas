- 2026-11-08: 두 화면 구현 · dev 실제 데이터로 확인(승인 · 반려된 QA 요청, C1 카드 — 「초안 1번은 v2 로 승인됨」으로 요청 칸이 꺼짐). dev 에 열린 요청이 없어 승인 · 보류 · 반려와 승인 요청 보내기는 컴포넌트 테스트(MSW)로만 확인했다
- 2026-11-08: dev 에서 처리 흐름 확인 — QA 카드 C990 초안을 같은 내용으로 다시 저장(4번)하고 화면에서 승인 요청 → 보류 → 반려를 두 번 돌렸다(승인은 하지 않음, 반려 요청 2건이 dev 에 남음). 처리 뒤 목록이 「대기」 칸에 남아 방금 처리한 요청이 안 보이던 것을 고쳐, 요청의 새 상태 칸으로 옮긴다
- 2026-11-09: MR !210 박준우 리뷰 「결과별 판단 문장(rule.outcomes[].claim_text)이 안 보인다」. 규칙은 초안이 아니라 주 지표 행에 있어(c3, 저장 때 rule 을 지움) `GET /v1/admin/indicators/{주 지표}` 로 받아 「판단」 칸에 결과마다 이름 · 문장을 넣었다(승인 요청 · 카드별 화면). 문장이 없는 결과는 판단 틀의 `{판정값}` 에 결과 이름, 근거 부족은 문장 없음(C2 와 같은 규칙). dev 의 C1 · A3 는 아직 규칙 1판(문장 없음)이라 판단 틀로 채운 줄이 보인다 — 카드 seed 를 다시 돌려 v3 가 되면 결과 문장이 나온다
