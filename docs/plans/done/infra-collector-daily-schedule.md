## 진행
- 2026-11-05: 시작. 증분 정제는 -191(출처 단위 · 수집 뒤 자동 정제)로 끝났고, 11/2 에는 「수집이 수동이라 시간 예약은 보류」로 두었다. 서버에 수집 timer 가 없음을 확인(DB 백업 timer 04:00 KST 만 있음)
- 2026-11-05: 넣을 출처 규칙 — 사람 손 없이 받을 수 있고(API · 게시판), 매일 새 자료가 생기고, 본문 폐기 규칙을 어기지 않는 것. 여수 보도자료(14일 창, 게시판 한 쪽) · 온통청년 · 기존 대응 후보. 스크립트는 단계마다 `issueatlas-collect --environment develop` 을 불러 잠금 · 로그 · 정제를 실행기에 맡긴다. 실행기를 중간에 죽이면 잠금만 풀리고 컨테이너가 남으므로 단계별 시간 제한 없이 unit `TimeoutStartSec=3h`. 파일은 `deploy/collector/schedule/` — 수집기 이미지 경로(`deploy/collector/*.py`) 밖이라 이 MR 이 수집기 이미지를 다시 만들지 않는다
