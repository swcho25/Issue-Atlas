- 2026-11-06: 호성 요청 — 「로그인 옆에 다크 · 라이트 버튼, 랜딩도 다크 모드, 토글은 Figma 토글 참고 · 애니메이션」. Figma 에 어두운 랜딩 시안이 없어 같은 차가운 회색 계열을 뒤집어 정했다(바탕 #0c0e13 계열 · 글자 #eef0f5 · 데이터 남색은 밝게). 도착 지도는 처음에 Fiord 로 구워 붙였다가 「기존 유지해도 될 듯」으로 밝은 지도 그대로 두었다 — 그래서 지도 위 표시(--landing-map-*)는 밝은 값 고정, 헤더는 지도 위에 있는 동안만(<html data-landing-map>) 밝은 화면 색
- 2026-11-06: 토글의 Figma 대각선 그라데이션 테두리 · 유리 효과는 다른 유리(lens · tab-glass)처럼 안쪽 빛 · backdrop-filter 로 옮겼다. 손잡이는 끝에서 살짝 넘쳤다 돌아오는 곡선(cubic-bezier 0.34, 1.56, 0.64, 1)

- 2026-11-08: 둘러보기 사진이 Figma 시안 캡처라 여수 경계가 바탕 지도와 어긋나 있었다 → 호성 요청으로 실제 화면으로 교체. develop 을 합친 뒤 로컬 개발 서버(dev 백엔드)에 일반 테스트 계정으로 로그인해 Playwright 로 1600 × 900 밝게 · 어둡게 찍었다. 실제 결과 지도에는 아직 측정소 · 기사 점이 없어 칸 설명을 지금 화면에 맞게 고쳤다. 같은 주소면 이미지 캐시가 옛 사진을 돌려줘 파일 이름을 새로 지었다(지금 tour-summary · argument · sources)
