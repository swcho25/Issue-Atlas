# feat/my-page — 마이페이지 · 로그아웃

- Jira: (MR 때 만든다) · 에픽 S15P31C108-57 화면 설계 · 지도

로그아웃할 곳이 없었다. 백엔드에는 `POST /v1/auth/logout`(204, CSRF 필요)이 이미 있다.
화면은 가운데 한 줄: 프로필 · 로그아웃 → 숫자 셋 → 묶음 목록(화면 · 최근 질문).
쓰는 API: `GET /v1/auth/me` · `GET /v1/me/questions` · `POST /v1/auth/logout`. 계약 · 백엔드는 바꾸지 않는다.
