  임시 컨테이너·볼륨 정리 확인. 같은 백업을 재사용해 불필요한 전체 백업 중복 생성 없음.

  수집·정제·근거·질문·논증·임베딩 데이터는 보존했다.
- 검증 결과: `/var/backups/issueatlas/backfill-rehearsal/20261109T024014Z/report.json`.
  원본 database.dump와 정리된 prepared.dump 합계 621,937,695 bytes(약 593MiB), root 0600.
  임시 컨테이너·볼륨·서버 임시 스크립트 삭제 확인. 두 API health UP,
  운영 V0014·보도자료 6,852건 유지. 서비스 DB 데이터·스키마·컨테이너는 변경하지 않음.

- 사용자 요청으로 위 연습 폴더 전체(database.dump·prepared.dump·report.json·로그)를 삭제하고
  경로 소멸 확인. 약 593MiB 회수, 기존 일일 자동 백업 7개 유지. 위 경로는 과거 검증 기록이며
