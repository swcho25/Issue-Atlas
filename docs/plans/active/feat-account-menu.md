# feat/account-menu — 계정 메뉴 · 로그아웃

- Jira: (MR 때 만든다) · 에픽 S15P31C108-57 화면 설계 · 지도

로그아웃할 곳이 없었다. 백엔드에는 `POST /v1/auth/logout`(204, CSRF 필요)이 이미 있다.
왼쪽 띠 맨 아래 첫 글자 동그라미를 누르면 오른쪽에 작은 판(이름 · 이메일 · 권한 / 로그아웃)이 뜬다.
쓰는 API: `GET /v1/auth/me`(띠가 이미 부름) · `POST /v1/auth/logout`. 계약 · 백엔드는 바꾸지 않는다.

## 완료 조건
- [x] 첫 글자 동그라미를 누르면 계정 판: 이름 · 이메일 · 권한(조회자 · 관리자), 그 아래 「로그아웃」
- [x] 바깥을 누르거나 Esc 로 닫는다(Esc 면 동그라미로 초점이 돌아간다)
- [x] 로그아웃하면 랜딩(/)을 페이지째 새로 연다. 세션이 이미 끝났으면(401) 그대로 랜딩으로, 그 밖의 오류는 판 안에 알린다
- [x] lint · typecheck · test · build 통과, 로컬에서 조회자 · 관리자로 밝게 · 어둡게 확인

  페이지에만 있는 것이 프로필 · 로그아웃뿐이었다 → 페이지를 빼고 띠의 계정 판으로 바꿨다(사용자 결정).
- 로그아웃은 `window.location.replace("/")`. `router.replace` 로 가면 Next 16(Cache Components)이 앞 화면 상태를
  기억해 같은 탭에서 다시 로그인했을 때 앞 사람의 상태(눌린 버튼 등)가 남았다. 남은 세션 쿠키는 랜딩 앞(proxy)이 지운다.
