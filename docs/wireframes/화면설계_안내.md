## 흐름

- 탐색 → 상세 → 경과·근거 → 원문
- 기관 자료 → 파일 선택 → 열 지정 → 처리 결과·실패 수정 → 지도 확인
- 정책 등록 → 결과 추적 → 평가 양식 → 내보내기
- 운영 관리 → 수집 현황 / AI 검수 / 분류 체계

## 구현 시 정리할 사항

- 이미지 시안이며 실제 작동하는 프로토타입은 아닙니다. 각 탭의 모든 선택 상태를 개별 이미지로 만들지는 않았습니다.
- 점수와 신뢰도를 구분합니다. 통계는 사건 점으로 표시하지 않습니다.
- 정책 결과는 시스템 판정으로 표시하며, 사용자 선택형 입력으로 구현하지 않습니다.
- 미관측 구간은 선으로 보간하거나 미래 관측값으로 표현하지 않습니다. 기준일 이후 값은 제공하지 않습니다.
- 기관 자료 공개 범위는 업로드 조직으로 제한합니다. 검수 대기는 점수에 넣지 않습니다.
- 기본 화면은 지도와 작은 도구만 표시합니다. 펼친 패널은 X로 닫고, 닫아도 지도 위치·기간·선택 이슈를 보존합니다.
- 운영 관리는 상단 메뉴에서 운영자에게만 노출하는 경로를 추가합니다.
- 최종 평가 양식·파일 형식·대표 이슈·카테고리는 팀 결정에 맞춰 교체합니다.
- 생성 이미지에는 문구·지도·날짜·일부 비이슈 강조색의 차이가 남을 수 있습니다. 실제 구현에서는 이슈 색상 외 UI를 중성색으로 통일합니다.
