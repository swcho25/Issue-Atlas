# handoff

다음 세션(사람 또는 다른 에이전트)이 이 파일 하나만 읽고 이어 갈 수 있게 한다.

1. 현재 브랜치의 실행 계획 `docs/plans/active/<branch 의 / 를 - 로>.md` 를 연다. 없으면 만들지 말고 아래 내용을 채팅으로만 남긴다.
2. 「진행」에 오늘 날짜로 추가
   - 한 일, 내린 결정과 이유
   - 마지막 검사 결과(`pnpm check` 통과/실패와 실패 내용)
3. 「다음 할 일 / 범위 밖」을 **바로 실행할 수 있는 문장**으로 다시 쓴다
   - 다음에 열 파일:줄, 실행할 명령, 막힌 원인과 시도해 본 것
   - 끝난 항목은 지운다
4. 완료 조건 체크박스를 실제 상태에 맞춘다.
5. 커밋하지 않는다. 커밋 안 된 변경이 있으면 그 사실을 「다음 할 일」 첫 줄에 적는다.
6. 계획 파일 경로와 「다음 할 일」 첫 항목을 알리고 끝낸다.
